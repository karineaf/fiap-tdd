# User Story - Publicar Mensagem

**Como** um usuário,
**Eu quero** poder publicar mensagens,
**Para que** outros usuários possam visuaLzar meu conteúdo e interagir com ele.

## Critério de Aceitação

1. Dexe permitir publicar mensagens
2. Um contador de "gostel" que começa com o valor 0
3. Yalidação de Conteúdo
4. Data de Criação dexe ser definida automaticamente
5. Qualquer usuário pode visualizar as mensagens existentes
6. Posao alterar a mensagem a qualquer momento
7. Posse remover a mensagen a qualquer momento
